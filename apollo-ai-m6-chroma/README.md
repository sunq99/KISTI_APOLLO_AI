## Apollo MODEL6 ChromaDB Server

- 글로벌 유망 아이템을 기업명 또는 설명 기반으로 유사도에 따라 조회하는 벡터 검색 서버
- ChromaDB를 벡터 DB로 사용하여 임베딩된 데이터를 저장 및 검색
- apollo-ai-m6 (Endpoints Server)로부터 호출됨

### 검색 방식

| 검색어 언어 | 검색 방식 |
|------------|----------|
| 영어 | 임베딩 기반 유사도 검색 |
| 한글 | Elasticsearch 기반 검색 |

### 기업명 검색 랭킹 기준

| 순위 | 조건 |
|------|------|
| 1순위 | 기업명과 완전일치 |
| 2순위 | 기업명과 일치 (대소문자 구분 없음) |
| 3순위 | 기업명으로 시작하는 아이템 |
| 4순위 | 기업명을 포함하는 아이템 |
| 5순위 | 유사도 알고리즘 점수 순 |
